# دفتر الفواتير

نظام لإدخال الفواتير والمستندات بالذكاء الاصطناعي: تصوّر المستند، والنظام يقرأه ويصنّفه ويحفظه، ويرفض أي مستند مرفوع من قبل.

- **الموقع / التطبيق:** https://abdoooalbadri-svg.github.io/invoices-app/
- **البيانات:** جدول Google «دفتر الفواتير» (ورقة «البيانات») والصور في Google Drive بحساب المدير.
- **الخادم:** Google Apps Script — الكود في `backend/Code.gs`.

## أنواع المستندات

| النوع | ينحسب في الإجمالي |
|---|---|
| فاتورة عادية | المبلغ كامل |
| فاتورة كهرباء / ماء | مستحقات الشهر الحالي فقط، في شهر الفاتورة |
| عقد إيجار | الإيجار الشهري × المدة، في شهر بداية العقد |
| إلغاء عقد إيجار | لا (ملاحظة للعلم مرتبطة بالعقد) |
| إيصال دفع | لا (ملاحظة للعلم مرتبطة بالفاتورة برقم الحساب ورقم الفاتورة) |

## منع التكرار

يُرفض المستند ولا يُحفظ إذا تطابق مع مستند موجود:

- نفس الصورة.
- فاتورة عادية: نفس الرقم ونفس المبلغ (أو بدون رقم: نفس التاريخ والمبلغ والمحل).
- كهرباء / ماء: نفس رقم الحساب ونفس الشهر، أو نفس رقم الفاتورة.
- عقد إيجار: نفس رقم العقد. إلغاء عقد: نفس رقم العقد ونفس تاريخ الإلغاء. إيصال: نفس رقم الإيصال.

## الملفات

- `index.html`, `app.css`, `app.js` — الواجهة (موقع وتطبيق PWA يعمل بدون إنترنت للرفع).
- `config.js` — رابط الخادم (`API_URL`، ينتهي بـ `/exec`).
- `sw.js`, `manifest.webmanifest`, `icons/` — التثبيت كتطبيق.
- `backend/Code.gs` — كود الخادم (يُلصق في محرر Apps Script المرتبط بالجدول). لا يحتوي على أي مفتاح سري: مفتاح Claude محفوظ في خصائص النص البرمجي.

## تحديث الخادم

1. الصق `backend/Code.gs` في ملف «الرمز.gs» في محرر Apps Script.
2. شغّل `setup` مرة واحدة (آمن على البيانات: يضيف أعمدة فقط).
3. نشر ← إدارة عمليات النشر ← ✏️ ← الإصدار الجديد ← نشر (نفس الرابط).
